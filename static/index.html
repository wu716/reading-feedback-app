使用说明

电脑和手机

坐下工作时用电脑：看项目、排日程、记录时间片。出门用手机：看日程、点「记」。账号是同一个。

1. 今日

  1. 打开先看日历和待办，再进入项目推进任务。
  2. 点日历上的某一天，可以为那天添加待办。添加时可选提醒时间，到点后会收到系统通知。

2. 日程

  1. 在日程中写下今天要处理的具体任务，再排成流程。
  2. 直接写下即可。写错了点「修改」；较大的事项可以在项目中拆分。
  3. 还没规划、但自己想做的，写在「记 → 以后想做」。不进今天、不提醒；准备好了再安排。

3. 项目

在项目里按阶段拆解任务，设置前置关系，并记录实际投入。

4. moment 与 idea

  1. 手机点底栏「记」，或三击音量减，先写下。电脑 Windows 应用按 Ctrl+Shift+K（全局），或窗口内 Ctrl+K / 点右下角「记」。去处可选 moment、idea 或 todo；全体默认 moment，可在「我的 → 快捷记下」改。
  2. todo 再选 today 或 later。idea 在「我的 → idea」。
  3. 电脑可开「小窗」，或把「记」拖到窗口边缘停靠。锁屏或其他应用上三击，需打开「三击音量减」开关。也可用磁贴或桌面快捷方式。

5. 我的

改昵称、开关提醒、打开「快捷记下」。这份说明随时可以再打开。
