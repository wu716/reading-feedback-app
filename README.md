# 书然 / Shuran

书然是一款面向个人目标、项目、日程与时间反思的应用。你可以把目标拆成阶段和任务，安排当天要做的事，记录实际投入，再核对结果并调整下一步。

当前源码包含项目任务与真实前置依赖、可切换的工作与休息时间片、手动补记、长期目标的活动与消费明细、日报到年报及阅读主题地图。日程、待办、「记」、账户和订阅继续保留。

## 旧功能与数据清理

自 `2.0.1` 起，书然源码已移除旧 EPUB 书架与阅读器、读书笔记抽取、阅读提醒及旧实践统计和独立看板的产品入口与专用 API。`2.0.2` 继续退出行动项、实践、习惯、方法卡、自我对话和旧 AI 建议。长期目标中的手动阅读记录与主题统计是新的生活记录能力，不依赖旧阅读器。独立的 `reader-app`（知间）是另一项目，不受此处代码变更影响。

生产数据清理由站长在部署新版后单独执行 [`scripts/retire_legacy_data.sh`](scripts/retire_legacy_data.sh)。脚本先验证旧写入路由已退出、新加坡补迁暂存表已清理，再备份完整数据库和上传卷，最后删除指定旧业务数据及 `uploads/ebooks`、`uploads/self_talks`。它保留账户、订阅、邀请码、日程、待办、项目、计时、「记」、审计和待办提醒数据。仓库操作本身不执行服务器清理。

## 版本与发布状态

- 当前源码版本：`2.0.14`，Android `versionCode 56`，网页静态版本 `20261021attention1`。免费保留记录、计时、日报、周报和本人数据导出；月报、季报、年报、深度分析与长期目标页的复盘目标／消费预算按有效套餐开放。站长人工收款与权益开通、续费、赠送、纠错、例外退款分别留痕。
- Android `2.0.14` 签名包已由 GitHub Actions 构建并发布；部署时按 Release 提供的 SHA-256 校验下载文件。服务器源码版本以 `/health` 为准；服务器实际提供的 APK 以 `/download/info` 为准，两者可能在部署过程中短暂不同。
- 下载接口核对 APK 包内版本、版本标记和发布元数据；不一致时停止提供更新。已排定的旧本机提醒需安装新版 APK 后才会清除。

设计、逐文件清理范围、增量迁移和数据保留边界见[产品转向审计](docs/product/2026-10-15-product-turn-audit.md)。当前操作见[书然使用说明书](docs/书然使用说明书.md)；部署前请先阅读[服务器部署说明](README_DEPLOYMENT.md)。
