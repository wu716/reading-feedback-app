# 书然 / Shuran

书然是一款面向个人目标、项目、日程与时间反思的应用。你可以把目标拆成阶段和任务，安排当天要做的事，记录实际投入，再核对结果并调整下一步。

当前源码包含项目任务与真实前置依赖、可切换的工作与休息时间片、手动补记、轻量验收、活动重要性回看和可复用的流程模板。原有方法卡、行动项、习惯、自我对话与账户功能仍保留。

## 阅读功能与历史数据

自 `2.0.1` 起，书然源码已移除阅读记录、EPUB 书架与阅读器、读书笔记抽取、阅读提醒及旧实践统计和独立看板的产品入口与专用 API。独立的 `reader-app`（知间）是另一项目，不受此处代码变更影响。

**功能退出不等于删除用户数据。**历史阅读记录、EPUB 元数据、笔记和上传文件继续保留，供完整备份及后续数据处置使用；本次没有执行数据库表、业务行或上传卷清理。
