# 书然 / Shuran

让学过的方法，用得上。

首发核心：保存「情境 + 第一步」方法卡，在实际遇到问题时尝试，记录「有帮助 / 没帮助 / 没用上」。未登录可在浏览器里体验，登录后保存到账号；站长可查看近 7 天实际使用与主动提交的意见。

版本：网页及 Android 安装包 `2.0` / `versionCode 42`。下载入口以 `/download/info` 的实际可用状态为准。
