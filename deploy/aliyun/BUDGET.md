# 书然 · 最低成本部署方案

## 方案 E：轻量服务器 + SQLite（约 ¥6–9/月）

适合：个人使用、内测、用户 < 50 人。

| 项目 | 费用 |
|------|------|
| 阿里云「轻量应用服务器」2核2G，**新用户年付** | 约 **¥68–99/年**（≈¥6–9/月） |
| 域名（可选，备案前可不用） | ¥30–50/年 |
| DirectMail 邮件 | 按量，早期几乎 ¥0 |
| DeepSeek API | 按调用量，早期约 ¥5–20/月 |

**架构：** 一台轻量服务器，Docker 只跑应用，数据库用 **SQLite 文件**（挂载磁盘卷，重启不丢）。

**优点：** 成本最低、运维最简单。  
**缺点：** 并发差、无自动主从备份；用户多了要升级。

---

## 方案 F：轻量 + Docker PostgreSQL（约 ¥6–9/月 + 0）

与方案 E 同一台机器，PostgreSQL 跑在 Docker 里（不另买 RDS）。

**比 RDS 方案每月省 ¥150–300**，适合早期有付费用户、但流量不大。

---

## 方案 G：备案前内测（约 ¥0–24/月）

| 方式 | 成本 |
|------|------|
| 仅本机运行 | ¥0（只有你自己能访问） |
| 轻量服务器 + IP 访问，无域名 | 同上轻量 ¥68–99/年 |
| 阿里云 / 腾讯云 **新用户代金券** | 常有 300–800 元代金券，首年更便宜 |

备案完成后再绑域名，不影响先部署。

---

## 推荐路径（书然早期）

```
第 1 步：买轻量服务器年付（新人 ¥68–99/年）
第 2 步：用 deploy/aliyun/docker-compose.budget.yml 部署（SQLite 或内置 PG）
第 3 步：IP + 端口内测，你账户迁移上去
第 4 步：并行做域名备案
第 5 步：备案后绑域名 + HTTPS
```

**何时升级：** 日活 > 50 或要接 Apple 正式上架 → 考虑 RDS 或更大规格 ECS。
