# 书然阅读实践反馈软件 V1.3.6 软件说明书

## 1 软件概述

### 1.1 软件全称与版本

软件全称：书然阅读实践反馈软件。  
软件简称：书然。  
版本号：V1.3.6。  
开发完成日期：2026年9月5日。  
开发方式：单独开发。  
权利取得方式：原始取得。

本说明书与软件著作权登记申请表、源程序鉴别材料使用同一软件全称和版本号。

### 1.2 软件用途

本软件面向有阅读习惯并希望把阅读收获落到日常行动中的个人用户。用户可将读书笔记提交给系统，由系统抽取可执行的行动项；也可手工新增行动。用户按日记录践行结果、阅读时长和自我对话，并通过统计看板查看完成情况与坚持情况。系统还提供每日提醒、阅读提醒和待办到点提醒，减少“读过却没有做过”的情况。

### 1.3 适用对象

本软件适用于以下使用场景：

1. 日常阅读后需要把笔记整理成下一步行动的个人用户。  
2. 希望对某一行动进行连续记录和回顾的用户。  
3. 需要在固定时间被提醒阅读、反思或处理待办的用户。  
4. 希望通过语音记录自我对话并转写为文字的用户。

### 1.4 运行方式

本软件由 Android 客户端与服务端共同构成。Android 客户端以原生外壳承载业务界面，通过网络访问服务端接口。用户也可在支持的浏览器中访问同一套业务功能。用户数据按账户保存在服务端，更换设备后使用同一账户登录即可继续使用。

## 2 运行环境

### 2.1 开发环境

1. 硬件：Intel 或 AMD 处理器，内存 8GB 及以上，硬盘剩余空间 20GB 及以上的个人计算机。  
2. 操作系统：Windows 10 或 Windows 11。  
3. 开发工具：Python 3.11、Android Studio、JDK 17。  
4. 编程语言：Python 3.11、Java 17、JavaScript、HTML、CSS、SQL。

### 2.2 运行环境

1. 客户端硬件：Android 7.0 及以上智能手机，内存 2GB 及以上。  
2. 客户端软件：Android 7.0 及以上操作系统，系统 WebView。  
3. 服务端运行支撑环境：Python 3.11、FastAPI、PostgreSQL 15。  
4. 网络：客户端与服务端之间需要可用的网络连接。  
5. 可选浏览器访问：Chrome 或同等内核的主流浏览器。

### 2.3 主要权限说明

Android 客户端在提供完整功能时，可能申请以下系统权限：网络访问、麦克风、通知、精确闹钟、开机恢复闹钟、忽略电池优化、安装应用更新。用户可在系统设置中查看和变更授权。未授予麦克风权限时，仍可使用上传音频文件的方式录入自我对话。未授予通知或闹钟权限时，到点提醒可能无法出现在通知栏。

## 3 系统结构

### 3.1 总体结构

系统分为四层：

1. 表现层：Android 原生外壳、Web 界面，负责登录、今日概览、笔记上传、行动管理、践行记录、自我对话、数据看板和个人中心等页面。  
2. 接口层：基于 FastAPI 的 HTTP 接口，负责身份校验、业务处理和数据读写。  
3. 业务层：行动抽取、践行记录、阅读统计、提醒调度、语音转写、智能建议等业务逻辑。  
4. 数据层：PostgreSQL 保存用户、行动、践行、阅读、待办、提醒和自我对话等数据；音频文件保存在服务端上传目录。

### 3.2 客户端结构

Android 客户端主要包含：

1. 主界面容器：使用 WebView 加载业务页面，处理页面跳转、文件选择和权限申请。  
2. 原生录音模块：在应用内录制自我对话音频并回传给页面。  
3. 提醒调度模块：将用户设定的每日提醒、阅读提醒和待办提醒写入系统闹钟。  
4. 提醒投递模块：到达设定时间后，将通知写入系统通知栏和顶部横幅。  
5. 开机恢复模块：设备重启后恢复已设定的提醒。  
6. 应用更新模块：检查服务端版本信息，下载并提示覆盖安装。

### 3.3 服务端主要模块

1. 账户模块：注册、登录、会话维持、昵称修改、账户注销。  
2. 行动模块：新增、编辑、删除、列表筛选、行动类型识别。  
3. 笔记模块：接收读书笔记文本，调用大语言模型抽取行动项。  
4. 践行模块：按行动和日期保存践行结果、文字反馈和评分。  
5. 阅读模块：保存阅读内容和时长，汇总当日阅读数据。  
6. 待办模块：保存当日待办、完成状态和提醒时间。  
7. 自我对话模块：接收音频、转写文本、播放记录和删除。  
8. 提醒模块：保存提醒开关与时间，向客户端提供待发送提醒。  
9. 统计模块：按时间范围和行动类型汇总完成情况、坚持情况和对比数据。  
10. 建议模块：针对单一行动提供智能建议和多轮对话。

### 3.4 主要数据对象

1. 用户：电子邮箱、昵称、密码哈希、账户状态、创建时间。  
2. 行动项：来源书籍、原文摘录、行动内容、状态、行动类型、时间计划。  
3. 践行记录：行动、日期、结果、备注、评分。  
4. 阅读记录：阅读内容、时长、日期。  
5. 每日待办：待办内容、完成状态、提醒时间。  
6. 自我对话：音频文件、转写文本、关联行动、创建时间。  
7. 提醒设置：总开关、每日提醒时间、阅读提醒、待办提醒等。  
8. 建议会话：与某一行动相关的对话记录。

## 4 安装与启动

### 4.1 安装 Android 客户端

1. 在 Android 7.0 及以上设备上，使用系统浏览器打开软件提供的下载地址。  
2. 下载安装包后，按系统提示允许安装来自此来源的应用。  
3. 安装完成后，桌面出现名称为“书然”的应用图标。  
4. 已安装用户再次安装新版本时，采用覆盖安装，不必先卸载。登录状态和云端数据会保留。

### 4.2 启动与首次进入

1. 点击桌面图标启动应用。  
2. 应用打开后进入登录或注册页面。  
3. 首次使用选择“注册”，填写电子邮箱和密码，密码不少于 6 位。  
4. 已有账户选择“登录”，填写电子邮箱和密码后进入今日页面。  
5. 若服务端开启邀请码，注册时还需填写有效邀请码。

### 4.3 检查更新

1. 进入“我的”或个人中心。  
2. 选择“检查更新”。  
3. 若当前版本低于服务端发布版本，按提示下载并覆盖安装。  
4. 若已是最新版本，页面提示当前版本号。

### 4.4 浏览器访问

在计算机或手机浏览器中访问服务端地址，使用同一账户登录后，可使用与客户端相同的主要业务功能。浏览器环境下，系统通知和原生录音能力受浏览器和系统限制，完整的到点通知和原生录音以 Android 客户端为准。

## 5 功能说明与操作

### 5.1 今日概览

今日概览是登录后的默认页面，用于查看当天的阅读、践行、待办和自我对话情况。

操作步骤：

1. 登录成功后自动进入今日页面。  
2. 查看当日阅读时长、已记录的践行次数和自我对话情况。  
3. 在“今日待办”中输入一条待办内容，保存后出现在当日列表。  
4. 完成某条待办后，勾选该待办，系统更新完成状态。  
5. 若为待办设置了提醒时间，到达该时间后，已授权通知的 Android 设备会在通知栏提示。  
6. 通过页面上的快速入口，进入上传笔记、行动项、数据看板或自我对话。

说明：页面数据在登录后自动加载，并在使用过程中定期刷新。待办按账户和自然日保存，主要用于安排当天要做的事，与长期行动项相互补充。

### 5.2 上传笔记并抽取行动

本功能把一段读书笔记转化为一条或多条行动项。

操作步骤：

1. 进入“上传笔记”。  
2. 选择“AI 抽取行动项”。  
3. 可选填写书籍名称，便于后续按书归类。  
4. 将读书笔记粘贴到“笔记内容”输入区。笔记长度需满足系统设定的最小和最大字数要求。  
5. 点击“抽取行动项”。  
6. 系统调用大语言模型分析笔记，生成若干行动项并写入当前账户。  
7. 进入“我的行动项”查看、编辑或删除生成结果。

笔记来源可以是微信读书划线导出、Kindle 笔记、Notion、Obsidian、Word 或其他文本。当前版本支持粘贴文本，不要求上传原文件。

若用户已经明确要做的事，不必使用自动抽取，可改用手工新增。

### 5.3 手工新增行动项

操作步骤：

1. 在上传笔记页面切换到“手动添加行动项”，或在行动列表中选择新增。  
2. 填写书籍名称和行动内容。  
3. 保存后生成一条行动项，状态默认为待办。  
4. 可继续为该行动设置时间、次数或提醒。

手工新增适用于目标已经清楚、不需要从长文中提取行动的情况。

### 5.4 保存阅读记录

当用户本次主要是阅读、暂不抽取行动时，可只保存阅读记录。

操作步骤：

1. 进入上传笔记或阅读记录入口。  
2. 切换到“阅读内容与笔记”。  
3. 填写本次阅读的内容摘要。  
4. 填写或选择阅读时长。  
5. 保存后，该记录计入当日阅读统计，并在今日概览中显示。

阅读记录与行动项相互独立。用户可以先记录阅读，之后再根据同一段笔记抽取行动。

### 5.5 我的行动项

行动项是本软件的核心对象。每条行动通常包含：行动内容、状态、来源书籍、原文摘录、行动类型。

行动类型分为两类：

1. 情境触发型：在特定情境出现时执行，例如遇到某种场合再说某句话或采取某个动作。  
2. 习惯养成型：需要按一定频率重复执行，例如每天或每周做一次。

状态包括待办、进行中和已完成。

常用操作：

1. 查看全部行动，或按情境触发型、习惯养成型筛选。  
2. 选择“记录实践反馈”，为当天保存一条践行结果。  
3. 选择“查看记录”，浏览该行动的历史践行。  
4. 选择“设置时间 / 次数”，为习惯型或情境型行动设定计划。  
5. 选择“AI 建议”，就该行动的进展和下一步进行对话。  
6. 选择“编辑”修改行动内容、书籍名称等信息。  
7. 选择“删除”移除不再需要的行动。删除后，该行动不再出现在常规列表中。

建议用户同时保留的重点行动不宜过多，可先选择一到三条持续记录，避免列表过长难以坚持。

### 5.6 记录践行

践行记录用于回答“这件事今天有没有做、做得怎样”。

操作步骤：

1. 在行动列表中找到目标行动。  
2. 选择“记录实践反馈”。  
3. 选择结果：成功、部分完成或未完成。  
4. 可选填写文字反馈，说明过程中的困难或收获。  
5. 可选给出评分。  
6. 保存后，该记录计入当日统计和该行动的历史记录。

同一行动在同一自然日通常只保存一条践行记录。若需要修改当天结果，应编辑已有记录，而不是重复新增。

践行记录是后续统计坚持天数、完成情况和智能建议的基础数据。没有践行记录时，统计和建议可用的信息较少。

### 5.7 实践统计

实践统计用于按时间查看行动完成情况和坚持情况。

可查看的内容包括：

1. 行动完成数量和未完成数量。  
2. 短期、长期和持续习惯等时间维度。  
3. 坚持天数、连续天数。  
4. 情境触发型与习惯养成型的对比。

建议用户按周查看一次，确认哪些行动在持续推进，哪些行动长期没有记录。

### 5.8 数据看板

数据看板提供比实践统计更完整的时间范围和分类视图。

操作步骤：

1. 从今日页面或导航进入“数据看板”。  
2. 选择时间范围，例如近 7 天、近 30 天或近 3 个月。  
3. 查看综合视图，了解总体阅读、行动和践行情况。  
4. 切换到情境触发型或习惯养成型视图，分别查看两类行动。  
5. 查看对比分析，了解两类行动的差异。  
6. 如系统已生成数据洞察，可阅读针对当前数据的说明。

数据看板依赖已经保存的阅读记录、行动项和践行记录。使用时间越长，可观察的趋势越清楚。

### 5.9 智能建议

智能建议针对某一具体行动，而不是给出空泛的一般性建议。

操作步骤：

1. 打开一条行动。  
2. 选择“AI 建议”。  
3. 可询问进展是否正常、如何降低执行难度、下一步如何安排等。  
4. 需要更细致的分析时，可选择深度思考模式。  
5. 根据返回内容调整行动表述、频率或提醒时间。

智能建议会参考该行动的类型、历史践行和已有反馈。用户仍需根据自身情况判断是否采纳。

### 5.10 自我对话

自我对话用于录制或上传一段口头反思，并转写为文字，便于回看。

录入方式：

1. 在 Android 客户端内使用原生录音。首次使用时，系统会申请麦克风权限。用户同意后开始录音，结束后保存。  
2. 上传已有音频文件。支持常见音频格式，文件大小需不超过系统限制。  
3. 在浏览器中录音。该方式依赖安全上下文，若当前访问环境不支持，应改用客户端录音或上传文件。

保存后的操作：

1. 查看和编辑转写文本。  
2. 播放音频。播放次数计入今日统计。  
3. 删除不再需要的记录。  
4. 可将自我对话与相关行动关联，便于对照。

若录音失败，客户端会提示当前缺少哪一项权限，并提供跳转到系统设置的入口。用户完成授权后可返回重试。

### 5.11 提醒

提醒用于在设定时间把“该做的事”送到通知栏，不要求用户整天停留在页面上。

可设置的提醒包括：

1. 提醒总开关。关闭后，各类提醒不再送达。  
2. 每日定时提醒。在固定时间提醒进行自我对话或当日回顾。  
3. 阅读提醒。到达每日阅读时间时提示开始阅读并记录。  
4. 待办提醒。某一待办到点时提示处理该待办。  
5. 完成行动后的提醒、新增行动后的提醒，以及较长时间未记录时的提醒。

Android 客户端中的到点提醒依赖系统闹钟和通知权限。建议用户在首次开启提醒时完成以下设置：

1. 允许通知。  
2. 允许精确闹钟或闹钟与提醒。  
3. 按设备厂商指引允许自启动或关联启动。  
4. 必要时忽略电池优化，避免系统在后台限制提醒投递。

设置或修改提醒时间后，客户端会把时间表写入本地闹钟。此后即使当天没有再次打开应用，只要设备处于正常开机状态且系统未清除该应用的闹钟，到达设定时间仍应弹出通知。

### 5.12 个人中心

个人中心用于管理账户信息和提醒开关。

可进行的操作：

1. 查看当前登录账户。  
2. 修改昵称。  
3. 开启或关闭提醒总开关。  
4. 设置每日提醒、阅读提醒和其他提醒选项。  
5. 检查应用更新。  
6. 退出登录。  
7. 在需要停止使用时申请注销账户。

退出登录后，本机不再以该账户身份请求接口。云端已经保存的数据不会因为退出登录而删除。注销账户将按系统规则处理该账户下的业务数据，操作前应确认不再需要这些数据。

## 6 典型使用流程

### 6.1 从读书笔记开始

1. 注册或登录。  
2. 将一段读书笔记粘贴到上传页面。  
3. 使用自动抽取生成行动项。  
4. 保留一到三条准备执行的行动，删除或搁置其余条目。  
5. 当天执行后记录践行结果。  
6. 一周后打开数据看板，查看这些行动是否仍在推进。

### 6.2 从明确目标开始

1. 登录后手工新增一条行动。  
2. 设置频率、时间或待办提醒。  
3. 按计划执行并记录结果。  
4. 使用智能建议调整行动表述或执行方式。

### 6.3 从阅读和反思开始

1. 先保存阅读记录和阅读时长。  
2. 使用自我对话录下当时的想法。  
3. 在个人中心打开每日提醒。  
4. 在提醒到达时补充践行或继续阅读。

## 7 界面与信息说明

### 7.1 主要界面

1. 登录与注册页：输入电子邮箱、密码，完成身份校验。  
2. 今日页：展示当日待办、阅读、践行和自我对话摘要。  
3. 上传笔记页：提供自动抽取、手工新增和阅读记录三种入口。  
4. 行动列表页：展示行动内容、类型、状态和操作按钮。  
5. 践行记录页：填写结果、反馈和评分。  
6. 自我对话页：录音、上传、转写、播放和删除。  
7. 数据看板页：按时间范围展示统计和分类对比。  
8. 个人中心页：账户、提醒、更新和退出。

### 7.2 主要输入项

1. 电子邮箱：作为登录标识，需符合邮箱格式。  
2. 密码：不少于 6 位。  
3. 书籍名称：用于标明行动来源，可为空或由用户自定。  
4. 笔记内容：用于自动抽取行动的文本。  
5. 行动内容：需要执行的具体事项，建议写清楚在什么情况下做什么。  
6. 阅读时长：以分钟为单位记录。  
7. 践行结果：成功、部分完成或未完成。  
8. 提醒时间：按小时和分钟设定。

### 7.3 主要输出项

1. 自动生成的行动项列表。  
2. 当日阅读时长和践行次数。  
3. 行动完成情况和连续坚持天数。  
4. 自我对话转写文本。  
5. 针对单一行动的智能建议。  
6. 系统通知栏中的到点提醒。

## 8 异常与注意事项

### 8.1 登录和网络

1. 无法打开页面时，应检查设备网络是否可用，以及服务端是否可访问。  
2. 登录失败时，应核对邮箱和密码，避免使用未注册的邮箱。  
3. 会话过期后，需要重新登录。重新登录不会丢失已经保存到云端的数据。

### 8.2 行动抽取

1. 笔记过短或过长可能无法抽取。  
2. 抽取结果不准确时，应编辑或删除对应行动，或改为手工新增。  
3. 自动抽取依赖服务端的模型调用额度。额度用尽时，应稍后重试或改用手工新增。

### 8.3 录音和通知

1. 未授予麦克风权限时，原生录音不可用，可改上传音频文件。  
2. 未授予通知权限时，提醒不会出现在通知栏。  
3. 部分设备厂商会对后台应用进行限制。若到点没有通知，应检查自启动、关联启动和电池优化设置。  
4. 设备关机、系统清除应用数据或用户关闭提醒总开关后，对应闹钟不会继续触发。

### 8.4 数据与隐私

1. 用户数据按账户隔离，普通用户不能查看其他账户的笔记、行动和音频。  
2. 密码以哈希形式保存，系统不向页面回传原始密码。  
3. 自我对话音频保存在服务端上传目录，删除记录后不再提供播放。  
4. 本软件使用大语言模型处理用户提交的笔记和部分行动信息，用户不应提交不适宜交给系统处理的内容。

### 8.5 更新与兼容

1. 覆盖安装保留登录数据和云端数据，不必卸载重装。  
2. 过旧的客户端可能无法使用较新的通知或录音能力，应检查更新。  
3. 客户端最低系统版本为 Android 7.0。低于该版本的设备不在支持范围内。
