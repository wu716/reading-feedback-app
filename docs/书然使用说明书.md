# 书然使用说明书

**版本：** 2.0.19（Android 源码 versionCode 61；安装包发布与服务器下载状态分别以 GitHub Release 和 `/download/info` 为准）

**更新日期：** 2026 年 10 月 22 日

书然帮助你把目标拆成能开始、能验收的个人项目任务，再用实际时间片回看投入。手机与网页使用同一个账号。

## 从哪里开始

1. 默认打开当天「日程」，直接安排简单事项；任务属性和顺序分别设置。需要分阶段交付时进入「项目」。
2. 建立一个有明确交付结果的项目。项目自动有「当前阶段」和「下一阶段」；想到后续步骤时先放进下一阶段。
3. 在当前阶段添加能开始的一步。熟悉程度、估时、目标作用和验收标准都可以稍后补齐。
4. 若 B 必须等 A 完成，在 B 的「前置与检查项」里添加 A。被阻塞的任务会标明等待关系；同一阶段的其他任务可以继续推进。
5. 简单事项仍可直接写入「日程」，不必建项目。

## 执行、验收和回看

- 独立「执行」工作区先加入本轮任务，再开始队首任务。默认 20 分钟工作、5 分钟休息，两者可调整；队列可用「上移 / 下移 / 移出」调整，设置保存在服务器。
- 到点自动挂起，未完成不等于失败，也不会自动勾选完成。选择「做下一项」将上一工作任务移到队尾，形成 A → B → A 的轮转；完成或等待前置的任务会跳过。也可明确选择继续当前任务一片或休息。休息结束后，等待你准备好再开始下一项。
- 「暂停」保留剩余时长，刷新后也能恢复；暂停和休息不计入任务实耗。离开或关闭页面后，服务器仍将工作片实耗截止在预定终点，不会把离开后的几小时记为工作。
- 忘记计时可在「执行 → 投入记录 → 补记实际投入」输入实际区间。也可选择一个自己记录过的「记·时刻」作为来源并确认区间。重叠区间会被拒绝，避免重复累计。
- 任务详情并列显示原估计、当前估计、实际投入和差额。完成时核对验收标准，选择「完成 / 部分完成 / 需要返工」，可写偏差原因。原估计不会随改估时被覆盖。
- 「回看实际时间」可按**当时目标**给实际活动标记「不重要 / 一般 / 重要」，也可另记是否有趣。没有评价的片段保持未标记；系统不会从日程优先级自动推断重要性。更改目标名称不改写已保存的评价文字快照。
- 「流程库」可从空白写步骤、检查项、常见难点和验收标准，也可从任务保存。调用后生成可编辑任务，后来修改模板不会追改已生成的任务。

## 日程与项目如何关联

- 在项目任务详情中选择日期并「写入日程」。同一任务同一天只保留一条有效安排；项目详情列出已安排日期，点日期可回到对应日程。
- 日程任务显示所属项目、累计投入和「加入时间片」。可以直接执行普通日程任务；需要长期推进时，点「纳入项目」，在项目页选好项目后明确确认，原日程与已有投入会保留并关联。
- 项目任务与日程共用同一个任务身份，计时和补记都会汇总到项目实耗；两边修改名称会同步。日程中的「验收」打开对应项目任务，核对完成标准后选择「完成 / 部分完成 / 需要返工」，结果同步到关联日程。验收完成会停止该任务的工作计时。
- 从日程移除安排只移除那天的安排，不删除项目任务和实际投入记录。

## 长期目标

顶部导航「长期目标」（手机底栏同名入口）按天记录读书、健身、帮朋友、陪家人、定投、写作、工作、放松八类用时。八个方向各占一行，直接展示当天累计时间；点击该行的「记录」展开补录区，可输入分钟数，也可用「+15」「+30」「+60」快速增加分钟。

可给「记·时刻」的区间明确归类，再补录没有进入日志的时间；同一段时间不要重复补录。旧时间日志不会自动归类或改写。切换日期时，本次页面会话保留各日期尚未保存的草稿；点击保存后才写入服务器，刷新或关闭页面前请先保存。

每日开销放在独立侧栏，手机上上下排列。注意力浪费按自定义分心事项填写分钟数，例如刷手机；当天没有此类事项时，点「今天没有注意力浪费」完成核对。注意力浪费单独统计，不并入活动总时长；活动中的「非计划占用」仍按活动单独展示。金钱消费按类别逐笔填写金额，退款记在实际到账日；没有消费时可确认当天无消费。定投金额单列，不计入金钱消费。

报告在独立区域通过「日报」「周报」「月报」「季度报」「年报」切换，周报按自然周统计。各报告分别汇总活动用时、注意力浪费事项和金额，并区分已核对、未记录和未到日期。

## 「记」、日程和其他功能

「记」分为时刻、idea 和以后想做。时刻记录当前时间，可在时间日志补充上一段做了什么；idea 留下念头；以后想做是尚未加入某个项目阶段的收集箱。三者分别保存，不会自动变成项目任务或实际工作时长。

手机前台约 1.5 秒内连按三下音量加可打开「记」；锁屏或其他应用中使用同一手势，需先在系统无障碍里开启「三击音量加 → 记」。荣耀手机若清理最近任务后自动关闭此授权，可在「应用启动管理」中允许书然后台活动，并在最近任务下拉书然卡片加锁，清理其他应用时保留书然。音量减双击手电和 YOYO 的电源键入口无需改动。系统仍可能撤销无障碍授权，书然不能自行重新授予。

Windows 默认进入当天「日程」，独立「今日」已撤下。左侧「日程」「执行」「项目」「流程库」分别承担安排、计时、阶段任务和复用方法。日程的清单、属性与排序分模式操作；旧待办保留日期、提醒和完成状态，并一对一接入日程。账户、订阅及待办提醒继续可用。

流程库可从空白建立，也可从项目任务保存；使用时明确选择日程日期或项目阶段。生成后的任务与模板分别保存，后续修改模板不会覆盖已有内容和勾选状态。补记与更正在「执行 → 投入记录」。

阅读、读书笔记抽取、实践统计页、独立数据看板、行动项、实践、习惯、方法卡、自我对话和旧 AI 建议已退出。部署新版后，站长将按独立脚本备份并清理这些板块的服务器数据。新版 Android 会清除旧阅读和自我对话闹钟；未升级的旧安装包仍可能按本机原计划提醒。

## 备份与升级

业务数据默认保存在服务器。站长执行旧数据清理前，脚本会做完整 PostgreSQL `pg_dump -Fc` 备份和上传卷备份；应用内 CSV 逻辑备份只作辅助，不能单独恢复上传原文件。不要手动清空 Docker 卷。Android 下载入口以 `/download/info` 确认安装包真实版本匹配发布元数据后再分发；源码版本递增不代表新版安装包已发布。
