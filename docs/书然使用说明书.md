# 书然使用说明书

**版本：** 2.0.23（Android 源码 versionCode 65；安装包发布与服务器下载状态分别以 GitHub Release 和 `/download/info` 为准）

**更新日期：** 2026 年 10 月 22 日

书然帮助你把目标拆成能开始、能验收的个人项目任务，再用实际时间片回看投入。手机与网页使用同一个账号。

## 从哪里开始

1. 默认打开当天「日程」，直接写任务，属性就近标记，顺序单独调整。需要分阶段交付时进入「项目」。
2. 建立一个有明确交付结果的项目。项目自动有「当前阶段」和「下一阶段」；想到后续步骤时先放进下一阶段。
3. 在当前阶段添加能开始的一步。估时、简单／困难、目标重要性和验收标准都可以稍后补齐；熟悉程度另列。
4. 若 B 必须等 A 完成，在 B 的「开始条件与约束」里添加 A。被阻塞的任务会标明等待关系；同一阶段的其他任务可以继续推进。
5. 简单事项仍可直接写入「日程」，不必建项目。

## 直接写任务和记录用时

日程保留纸色与宋体任务文字，使用灰蓝、墨蓝强调。写任务的输入区同时展示「熟悉／陌生」「简单／困难」「不重要／一般／重要」与预计用时，可以边写边设置，文字和属性可随时交替修改，没有先后顺序。属性始终可见、均可留空；输入任务或预计用时时按回车添加，当前文字和属性一起保存。中文输入法选字的回车不会提交。实际用时在执行后记录。

点已添加任务的标题可修改文字，点击已选标记可取消。熟悉度、难度和目标重要性独立保存，旧优先级不自动改成新的重要性。预计与实际用时仍可就近修改，点「保存用时」即可，可写分钟数或「1小时30分」。实际用时是任务累计总量，不与已有计时记录再次相加，也不会自动完成任务。普通任务点文字「完成」即可；有交付检查或项目验收的任务仍核对原有标准。

「设计流程」进入先后顺序与并行关系的设计，点「完成设计」返回；其中仍可边写新任务边设置属性。「查看流程」呈现已安排的先后与并行。完整预演、反馈历史、目标重要性修订在任务「更多」中打开；当天安排与回顾在列表末尾「计划与回顾」中按需打开。

任务操作集中在用时下面。「拆开」只打开更具体的一步，写完按回车或点「加入」；「更多」按准备与回顾、归属与开始分组，两者分别展开和收起。展开后继续使用纸面文字按钮，输入和操作保持在同一内容区域。

## 安排、预演与反馈

- 日程列表末尾「计划与回顾 → 打开当天计划与回顾」先保存当天目标、可用分钟及每项当天计划投入；跨日累计估计与当天分配分别保存。再根据“完成任务是否确实有益于达成目标”作首次标记及再次审视。新的重要性只有不重要、一般、重要；旧优先级保留来源，不自动转换。新安排的一天需要当天审视。
- 日程和项目任务都有「开始前预演」：第一步和顺序、材料准备、最可能的难点、卡住时的应对。需要时才填写；准备可以明确转为检查项或筹备任务。执行区显示本次开始时保存的第一步、准备和应对。旧预演笔记保留。
- 「有点难开始」按担心做不好、在意评价、任务不清楚、起步晚、挫折提供简短支持，可以接着开始5分钟，也可以直接关闭。
- 「用时反馈」一次核对完成／部分完成／返工、原估计、当前估计、区间投入、确认总量、偏差原因和下次估计经验。修改当前估计不会覆盖原值；再次估时可自己选择参考哪次经验。
- 只记得总分钟可以自报，不伪造起止时间，也不与已有工作片相加。跨日任务显示累计反馈，日报仍只统计当天真实区间。缺少记录时保持待核对，不默认填0；范围变化和执行后补填不计为可比估时样本。
- 「困难进展」记录已推进、已解决、阻碍和下一步，区分有进展、已核对无投入、记录不完整，可减少提示。困难、重要性与熟悉程度互相独立。
- 当天明确反馈是否做了有趣但无助于当时目标的事，区分有、没有、不确定和稍后；可以引用已有活动。日报、周报在原报告入口呈现，相关时间只引用，不与注意力浪费或非计划占用再次相加。

## 可行性、当前承诺与计划周期

- 目标和项目有独立可行性判断，明确提醒“计划成功的前提是目标现实可行”“已经有人做到了”“我与那个人没有太大的差距”，继续核对方法、耗时、起点、资源、差距和期限。没有案例可先探索，两个选择不等于成功保证。目标、期限和停止决定可以带原因修订，历史判断保留。
- 正式开始项目或确认当前列表时记录承诺范围。后续想法先放「下一阶段」，不混入当前执行；正常轮转、暂停、休息不等待。
- 提前移出未完成任务、缩减标准、撤销必要前置或切换阶段，进入「当前承诺与调整」：逐项选择保留推进、延期或取消，先看任务、依赖链、交付、投入和时间预算影响，再前台暂停30秒。后台暂停、刷新恢复、多页不能加速；原因完整且时间满后仍需主动确认。「继续当前列表」随时可用。先明确暂停正在运行的工作片，等待不算实耗。
- 草稿编辑和当前任务全部完成后的正常交接不强制等待。旧阶段、承诺版本、调整原因、去向、工作片和结果保留。取消不会冒充完成；原交付受到影响时先明确调整结果，再核对真实交付。
- 检查列表分准备／交付核对，支持增改、上下移、勾选和说明不适用；完成时先展示未核对项，可以补查或记录本次例外。开始条件、流程步骤与验收标准分别管理。
- 「计划周期与复盘」从一周试起，也可选两周、一个月、季度、年度或自定。保存日期、可检验结果、任务范围和可用时间；周期结束对照原计划与实际结果、区间投入、困难及条件变化，说明下一轮内容、方法、负荷和跨度决定，再制定下一轮。跨度没有解锁门槛，建议不只依赖完成率。

## 执行、验收和回看

- 独立「执行」工作区先加入本轮任务，再开始队首任务。默认 20 分钟工作、5 分钟休息，两者可调整；队列可用「上移 / 下移 / 移出」调整，设置保存在服务器。
- 到点自动挂起，未完成不等于失败，也不会自动勾选完成。选择「做下一项」将上一工作任务移到队尾，形成 A → B → A 的轮转；完成或等待前置的任务会跳过。也可明确选择继续当前任务一片或休息。休息结束后，等待你准备好再开始下一项。
- 「暂停」保留剩余时长，刷新后也能恢复；暂停和休息不计入任务实耗。离开或关闭页面后，服务器仍将工作片实耗截止在预定终点，不会把离开后的几小时记为工作。
- 忘记计时可在「执行 → 投入记录 → 补记实际投入」输入实际区间。也可选择一个自己记录过的「记·时刻」作为来源并确认区间。重叠区间会被拒绝，避免重复累计。
- 任务详情并列显示原估计、当前估计、实际投入和差额。完成时核对验收标准，选择「完成 / 部分完成 / 需要返工」，可写偏差原因。原估计不会随改估时被覆盖。
- 「回看实际时间」可按**当时目标**给实际活动标记「不重要 / 一般 / 重要」，也可另记是否有趣。没有评价的片段保持未标记；系统不会从日程优先级自动推断重要性。更改目标名称不改写已保存的评价文字快照。
- 「流程库」可从空白写步骤、检查项、常见难点和验收标准，也可从任务保存。调用后生成可编辑任务，后来修改模板不会追改已生成的任务。

## 日程与项目如何关联

- 在项目任务详情中选择日期并「写入日程」。同一任务同一天只保留一条有效安排；项目详情列出已安排日期，点日期可回到对应日程。
- 日程任务通过「更多」显示所属项目，已有计时投入就近显示，用「加入执行」排入轮转。可以直接执行普通日程任务；需要长期推进时，点「纳入项目」，在项目页选好项目后明确确认，原日程与已有投入会保留并关联。
- 项目任务与日程共用同一个任务身份，计时和补记都会汇总到项目实耗；两边修改名称会同步。日程中的「验收」打开对应项目任务，核对完成标准后选择「完成 / 部分完成 / 需要返工」，结果同步到关联日程。验收完成会停止该任务的工作计时。
- 从日程移除安排只移除那天的安排，不删除项目任务和实际投入记录。

## 长期目标

顶部导航「长期目标」（手机底栏同名入口）按天记录读书、健身、帮朋友、陪家人、定投、写作、工作、放松八类用时。八个方向各占一行，直接展示当天累计时间；点击该行的「记录」展开补录区，可输入分钟数，也可用「+15」「+30」「+60」快速增加分钟。

可给「记·时刻」的区间明确归类，再补录没有进入日志的时间；同一段时间不要重复补录。旧时间日志不会自动归类或改写。切换日期时，本次页面会话保留各日期尚未保存的草稿；点击保存后才写入服务器，刷新或关闭页面前请先保存。

每日开销放在独立侧栏，手机上上下排列。注意力浪费按自定义分心事项填写分钟数，例如刷手机；当天没有此类事项时，点「今天没有注意力浪费」完成核对。注意力浪费单独统计，不并入活动总时长；活动中的「非计划占用」仍按活动单独展示。金钱消费按类别逐笔填写金额，退款记在实际到账日；没有消费时可确认当天无消费。定投金额单列，不计入金钱消费。

报告在独立区域通过「日报」「周报」「月报」「季度报」「年报」切换，周报按自然周统计。各报告分别汇总活动用时、注意力浪费事项和金额，并区分已核对、未记录和未到日期。

## 「记」、日程和其他功能

「记」分为时刻、idea 和以后想做。时刻记录当前时间，可在时间日志补充上一段做了什么；idea 留下念头；以后想做是尚未加入某个项目阶段的收集箱。三者分别保存，不会自动变成项目任务或实际工作时长。

手机前台约 1.5 秒内连按三下音量加可打开「记」；锁屏或其他应用中使用同一手势，需先在系统无障碍里开启「三击音量加 → 记」。荣耀手机若清理最近任务后自动关闭此授权，可在「应用启动管理」中允许书然后台活动，并在最近任务下拉书然卡片加锁，清理其他应用时保留书然。音量减双击手电和 YOYO 的电源键入口无需改动。系统仍可能撤销无障碍授权，书然不能自行重新授予。

Windows 默认进入当天「日程」，独立「今日」已撤下。左侧「日程」「执行」「项目」「流程库」分别承担安排、计时、阶段任务和复用方法。日程的清单、属性与排序分模式操作；旧待办保留日期、提醒和完成状态，并一对一接入日程。账户、订阅及待办提醒继续可用。

流程库可从空白建立，也可从项目任务保存；使用时明确选择日程日期或项目阶段。生成后的任务与模板分别保存，后续修改模板不会覆盖已有内容和勾选状态。补记与更正在「执行 → 投入记录」。

## 备份与升级

业务数据默认保存在服务器。站长执行旧数据清理前，脚本会做完整 PostgreSQL `pg_dump -Fc` 备份和上传卷备份；应用内 CSV 逻辑备份只作辅助，不能单独恢复上传原文件。不要手动清空 Docker 卷。Android 下载入口以 `/download/info` 确认安装包真实版本匹配发布元数据后再分发；源码版本递增不代表新版安装包已发布。
