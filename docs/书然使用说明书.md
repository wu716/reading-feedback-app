# 书然使用说明书

**版本：** 2.0.1（versionCode 43）

**更新日期：** 2026 年 10 月 15 日

书然帮助你把目标拆成能开始、能验收的个人项目任务，再用实际时间片回看投入。手机与网页使用同一个账号。

## 从哪里开始

1. 在「项目」写下近期目标。可以先从一周开始，随后再设两周或一个月，不需要一开始规划全年。
2. 建立一个有明确交付结果的项目。项目自动有「当前阶段」和「下一阶段」；想到后续步骤时先放进下一阶段。
3. 在当前阶段添加能开始的一步。熟悉程度、估时、目标作用和验收标准都可以稍后补齐。
4. 若 B 必须等 A 完成，在 B 的「前置与检查项」里添加 A。被阻塞的任务会标明等待关系；同一阶段的其他任务可以继续推进。
5. 简单事项仍可直接写入「日程」，不必建项目。

## 执行、验收和回看

- 「现在做」默认建议 20 分钟工作、5 分钟休息，两者可调整。一次只有一个主要工作片；切换任务会结束上一片。暂停和休息不计入任务实耗。
- 忘记计时可在「事后补记」输入实际区间。也可选择一个自己记录过的「记·时刻」作为来源并确认区间。重叠区间会被拒绝，避免重复累计。
- 任务详情并列显示原估计、当前估计、实际投入和差额。完成时核对验收标准，选择「完成 / 部分完成 / 需要返工」，可写偏差原因。原估计不会随改估时被覆盖。
- 「回看实际时间」可按**当时目标**给实际活动标记「不重要 / 一般 / 重要」，也可另记是否有趣。没有评价的片段保持未标记；系统不会从日程优先级自动推断重要性。更改目标名称不改写已保存的评价文字快照。
- 「流程库」可从空白写步骤、检查项、常见难点和验收标准，也可从任务保存。调用后生成可编辑任务，后来修改模板不会追改已生成的任务。

## 「记」、日程和其他功能

「记」分为时刻、idea 和以后想做。时刻记录当前时间，可在时间日志补充上一段做了什么；idea 留下念头；以后想做是尚未加入某个项目阶段的收集箱。三者分别保存，不会自动变成项目任务或实际工作时长。

「今日」保留日历与待办；「日程」保留当日安排、属性标注和排序模式；「行动」与习惯、自我对话、AI 建议、账户和订阅继续可用。添加行动项可直接手动输入。

阅读、读书笔记抽取、实践统计页和独立数据看板已退出。已有阅读记录、EPUB、笔记及历史统计数据保留在服务器数据库和上传卷中，但新版不再提供阅读入口。升级后的 Android 会清除旧阅读提醒；未升级的旧安装包仍可能按本机原计划提醒。

## 备份与升级

业务数据默认保存在服务器。站长应在部署前做完整 PostgreSQL `pg_dump -Fc` 备份和上传卷备份；应用内 CSV 逻辑备份只作辅助，不能单独恢复上传原文件。不要删除数据库表、业务记录或 Docker 卷。Android 下载入口以 `/download/info` 确认有匹配 `versionCode 43` 的安装包后再分发。
