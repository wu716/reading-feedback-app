## 一、书然是做什么的？

你可能有过这种感受：

- 书读了不少，笔记记了很多  
- 当时觉得「这个我要改」「这个我要做」  
- 过几周再翻，已经忘了要从哪条开始  

**书然帮你做三件事：**

1. **上传笔记，自动提取行动** —— 不用一条条手填  
2. **记录践行，长期跟踪** —— 不是读完就忘  
3. **用数据看清自己** —— 哪些在坚持，哪些总落下

## 二、5 分钟快速上手

### 第 1 步：注册 / 登录

1. 打开体验地址  
2. 首次使用点 **「注册」**，填写邮箱、密码（至少 6 位）  
3. 已有账号直接 **「登录」**

### 第 2 步：上传笔记，提取行动（核心功能）

1. 左侧点 **「上传笔记」**  
2. 选 **「AI 抽取行动项」**  
3. 可选填书籍名称  
4. 把电子读书笔记 **复制粘贴** 到「笔记内容」（10～10000 字）  
5. 点 **「抽取行动项」**  
6. AI 会自动生成若干「行动项」，可在 **「我的行动项」** 中查看  

> **说明：** 目前支持 **粘贴文本**，暂不支持直接上传 .txt / .pdf 文件。  
> 微信读书、Kindle、Notion 等笔记，复制一段过来即可。

### 第 3 步：记录一次践行

1. 左侧点 **「我的行动项」**  
2. 找到一条行动，点 **「记录实践反馈」**  
3. 选择结果（成功 / 部分完成 / 未完成），可选写反馈、打星  
4. 点 **「保存实践记录」**

### 第 4 步：看今日情况

1. 左侧点 **「首页概览」**  
2. 查看 **今日阅读时长、实践行动、践行记录** 等  

**完成以上 4 步，你就走通了书然的主流程。**

## 三、功能详解

### 1. 首页概览

| 模块 | 作用 |
|------|------|
| **今日待办** | 添加当天临时待办，可勾选完成 |
| **今日概览** | 汇总今日阅读、践行、Self-talk 等 |
| **快速操作** | 一键跳转到上传笔记、行动项、数据看板等 |

登录后数据会自动加载，约每 2 分钟刷新。

---

### 2. 上传笔记（三种方式）

#### 方式 A：AI 抽取行动项（推荐）

- **适合：** 已有较长读书笔记，想快速得到「该做什么」  
- **操作：** 粘贴笔记 → 点「抽取行动项」  
- **结果：** 系统自动创建多条行动项  

#### 方式 B：手动添加行动项

- **适合：** 心里已经明确要做什么，不需要 AI  
- **操作：** 切换到「手动添加行动项」，填写书籍名、行动内容  
- **结果：** 直接生成一条行动  

#### 方式 C：保存阅读记录

- **适合：** 这次主要是阅读，暂时不抽行动  
- **操作：** 切换到「阅读内容与笔记」，填写内容、时长  
- **结果：** 计入今日阅读数据  

---

### 3. 我的行动项

每条行动会显示：

- 行动内容、状态（待办 / 进行中 / 已完成）  
- 来源书籍、原文摘录  
- 类型：**情境触发型** 或 **习惯养成型**  

**常用操作：**

| 按钮 | 作用 |
|------|------|
| **记录实践反馈** | 记录今天有没有做、做得怎样 |
| **查看记录** | 看历史践行记录 |
| **设置时间 / 次数** | 为习惯型或情境型设定计划 |
| **AI 建议** | 针对该行动与 AI 对话，获取建议 |
| **编辑 / 删除** | 修改或移除行动 |

**筛选：** 可按「全部 / 情境触发型 / 习惯养成型」查看。

---

### 4. 实践统计

查看：

- 行动完成情况  
- 时间维度分析（短期 / 长期 / 终身习惯）  
- 坚持度、连续天数等  

适合 **每周回顾** 时使用。

---

### 5. Self-talk（内心对话）

**作用：** 录下或上传一段内心对话，转写为文字，方便回顾与强化。

**两种录入方式：**

| 方式 | 说明 |
|------|------|
| **上传音频文件** | ✅ 当前内测环境 **推荐** |
| **浏览器录音** | ⚠️ 需 HTTPS 或 localhost；当前 HTTP 地址下可能不可用 |

**支持音频格式：** wav、mp3、m4a、ogg、webm、mp4（最大 50MB）

**上传后：** 可编辑转写文字、播放、删除；播放次数会计入首页统计。

---

### 6. 数据看板

路径：**数据看板** 或首页「查看仪表盘」

- 可选时间范围：近 7 天 / 30 天 / 3 个月等  
- 综合视图、情境触发型、习惯养成型、对比分析  
- 含 AI 数据洞察  

适合 **想看清长期规律** 时使用。

---

### 7. AI 行动建议

在「我的行动项」中，对某条行动点 **「AI 建议」**：

- 可问：进展如何、怎么改进、下一步计划等  
- 支持标准模式 / 深度思考模式  

---

### 8. 个人中心 & 提醒

路径：**个人中心**

| 设置 | 说明 |
|------|------|
| **修改昵称** | 最多 6 个字 |
| **启用提醒** | 总开关 |
| **每日定时提醒** | 固定时间提醒做 Self-talk |
| **完成行动后提醒** | 践行后提醒记录反思 |
| **添加新行动后提醒** | 新建行动时提醒 |
| **长期未记录提醒** | N 天未使用时提醒 |
| **浏览器通知** | 需浏览器授权 |
| **邮件通知** | 内测阶段逐步开放 |

## 四、推荐使用路径

### 路径 A：从读书笔记开始（最典型）

```
上传笔记 → AI 抽行动 → 选 1～3 条重点行动 → 每天记录践行 → 周末看数据看板
```

### 路径 B：已有明确目标

```
手动添加行动 → 设置时间/频率 → 每天践行打卡 → AI 建议优化
```

### 路径 C：阅读 + 反思

```
保存阅读记录 → Self-talk 上传音频 → 个人中心开提醒 → 定期回顾
```

## 六、常见问题

**Q：笔记从哪里复制？**  
A：微信读书划线导出、Kindle 笔记、Notion、Obsidian、Word 等均可，复制文本粘贴即可。

**Q：AI 抽的行动不准怎么办？**  
A：可手动编辑、删除多余的，或用手动添加。内测阶段欢迎反馈「哪里抽错了」。

**Q：同一天能记多次践行吗？**  
A：同一行动项 **同一天只能记一条** 践行记录。

**Q：换设备数据还在吗？**  
A：在。用同一账号登录即可，数据在云端。

**Q：忘记密码？**  
A：内测阶段请联系群主重置。

**Q：Self-talk 录音按钮不能用？**  
A：请改用 **上传音频文件**；或等正式 HTTPS 域名上线后使用浏览器录音。
