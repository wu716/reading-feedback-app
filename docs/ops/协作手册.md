# 书然协作手册

## 2026-10-20：独立判断与主动改进

用户希望协作者有自己的判断，能够挑战用户想法、补充遗漏，提出并落实更好的方案。不要一味顺应，也不要刻意争辩；用具体理由、证据和替代方案推进目标。有重要歧义或不可逆取舍时先对齐，已授权范围内的合理实现选择主动完成。

修改前先用中文说明理解、范围、遗漏和设计。新增约定同步写入本手册与 AGENTS.md。交付区分本地提交、GitHub 推送、服务器部署和真实验证结果。

生产部署由用户执行，提供 Windows PowerShell SSH 登录命令和 Ubuntu 完整更新、构建、健康检查命令。业务数据在服务器保存，本地验证只使用内存数据库或专用测试数据。

## 2026-10-21：本地项目目录与安装包清理

`D:\projects` 专门存放独立项目，书然只保留 `D:\projects\reading-feedback-app` 一个常驻工作目录。日常任务优先使用主项目目录；确需临时工作树时，完成后核对未提交改动与分支提交，再移除或归档，不在 C 盘或 `D:\projects` 留下书然副本。测试脚本、截图等资料归入 `D:\UserData\ProjectArtifacts\reading-feedback-app`，个人文件放到对应的用户资料目录。其他独立项目与个人数据不能仅凭名称或目录数量删除。

APK 确认已上传发布且可下载后，清理本地安装包与构建副本；保留需要的源码、版本元数据和签名材料，生产服务器上的安装包由部署流程单独维护。

## 2026-10-21：深度复盘与人工开通

书然面向个人项目与生活管理用户，付费价值是软件生成的深度复盘。免费保留完整记录、计时、日报和周报、历史查看及本人数据导出；有效付费套餐开放月报、季报、年报、跨期对比、阅读主题等深度分析，以及长期目标页的复盘目标与消费预算。项目目标的创建仍免费；消费分类的记录与日、周分类汇总仍免费。

当前不接入应用内支付。用户先在产品群了解权益与售后，再向站长付款；站长核对到账后在后台为指定账号开通，并登记金额、渠道、北京时间、可核对的转账单号和前后到期日。偏离目录价时须备注原因。提前续费及换付费套餐都从有效旧到期日顺延。赠送、权益纠错和依法处理的例外退款分别留痕；原则上不支持自愿退款，但不能排除法定或未按约提供服务的处理责任。生产业务数据保存在服务器，本地检查使用内存数据库。对外宣传必须先核对实际部署版本，不引用已移除的旧 AI 阅读功能。
