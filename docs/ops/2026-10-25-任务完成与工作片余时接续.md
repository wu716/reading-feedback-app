## 已审核行为

任务完成立即结束它的真实投入区间，保存本片剩余秒数；等待选择不计时。可用余下时间开始另一项，或者提前结束本片并休息。例如 A 第一片做20分钟，第二片做10分钟后完成，则 A 记录30分钟；B 只获得第二片剩余约10分钟。B 到时后按现有设置自动休息。未用时间不补成投入，也不算休息。

## 数据和兼容

复用 ExecutionPlan.paused_session_id / remaining_seconds；已完成的投入段在现有 practice_snapshot_json 内记录 execution_handoff 标记，与普通暂停区分。无需新增表或数据库迁移，不修改历史区间，不创建补偿性虚拟记录。handoff 字段供新网页恢复决策状态；旧客户端即使请求完整20分钟，服务端也以保存余时为准，不扩大本片预算。开始休息或明确放弃余时后清空待转交状态。

完成入口沿用项目/日程的完成条件与清单检查；关联项目的普通日程仍须到项目核对验收，不允许用快捷按钮绕过，项目验收成功后同样保留余时。完成失败不转交余时；重复完成已关闭的工作片返回冲突；普通暂停仍可恢复原任务。执行页提供“完成当前任务”，完成后显示余时与选择。原生提醒在等待选择时撤销，在开始下一项时使用新的服务器截止时间，不改变已选定的回落拨弦。


```bash
sudo -i
cd /opt/shuran-app
git pull origin main
install -m 644 /home/ubuntu/shuran-2.0.33.apk releases/shuran.apk
printf '75\n' > releases/shuran.apk.versioncode
cd deploy/aliyun
```
