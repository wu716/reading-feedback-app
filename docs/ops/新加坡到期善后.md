# 新加坡到期善后（三天内）

最后更新：2026-09-17。

## 结论

- **生产只靠香港** `43.161.238.165:8000`。
- **新安装包 / 桌面 / `latest.json` / 默认 API 只指向香港**，不依赖新加坡。
- **旧外壳 1.3.4 写死新加坡**。新加坡关机后：旧外壳打不开更新、也连不上业务 API。必须在到期前升到 **1.5.4（versionCode 20）**。
- **善后完成且你确认之前，不要关新加坡。** 确认全员可登录香港、更新挡板装的是 1.5.4 后，再关。

## 到期前必须做完（按顺序复制）

### 1. 本机已打好正确 APK

确认文件是 1.5.4 / versionCode 20（不要再用 1.5.2）：

```powershell
# 当前目录：D:\projects\reading-feedback-app
$aapt = Get-ChildItem "$env:LOCALAPPDATA\Android\Sdk\build-tools" -Recurse -Filter aapt.exe | Sort-Object FullName -Descending | Select-Object -First 1
& $aapt.FullName dump badging .\releases\shuran.apk | Select-String "package:"
```

成功：一行里有 `versionCode='20'` 和 `versionName='1.5.4'`。

### 2. 登录香港，拉代码并放入 APK

```bash
ssh ubuntu@43.161.238.165
```

```bash
sudo -i
cd /opt/shuran-app && git pull origin main && cd deploy/aliyun && docker compose up -d --build
```

另开 **PowerShell** 上传安装包（香港）：

```powershell
# 当前目录：D:\projects\reading-feedback-app
scp .\releases\shuran.apk ubuntu@43.161.238.165:/tmp/shuran.apk
scp .\releases\shuran.apk.versioncode ubuntu@43.161.238.165:/tmp/shuran.apk.versioncode
```

香港 SSH 里：

```bash
sudo mkdir -p /opt/shuran-app/releases
sudo mv /tmp/shuran.apk /opt/shuran-app/releases/shuran.apk
sudo mv /tmp/shuran.apk.versioncode /opt/shuran-app/releases/shuran.apk.versioncode
sudo chmod 644 /opt/shuran-app/releases/shuran.apk /opt/shuran-app/releases/shuran.apk.versioncode
curl -s http://127.0.0.1:8000/download/info
```

成功：JSON 里 `"available": true`，`"versionCode": 20`，且最好有 `"apk_version_code": 20`。

### 3. 新加坡最后一次同步（到期前保留）

旧 1.3.4 仍向新加坡要 `/download/info` 与 `/download/apk`，所以新加坡也要有同一份正确包：

```bash
ssh root@47.236.122.207
```

```bash
cd /opt/shuran-app 2>/dev/null || cd /root/reading-feedback-app
git pull origin main
# 若用 docker：
cd deploy/aliyun && docker compose up -d --build
```

本机上传到新加坡：

```powershell
scp .\releases\shuran.apk root@47.236.122.207:/tmp/shuran.apk
scp .\releases\shuran.apk.versioncode root@47.236.122.207:/tmp/shuran.apk.versioncode
```

新加坡上：

```bash
mkdir -p /opt/shuran-app/releases
mv /tmp/shuran.apk /opt/shuran-app/releases/shuran.apk
mv /tmp/shuran.apk.versioncode /opt/shuran-app/releases/shuran.apk.versioncode
curl -s http://127.0.0.1:8000/download/info
```

成功：同样 `"available": true`、`versionCode` 20。  
（若新加坡容器挂载路径不是 `/opt/shuran-app/releases`，把文件放到该机实际 `releases/` 目录。）

### 4. 手机验证

1. 打开书然 → 点「立即更新」→ 若再弹出系统/原生「需要更新」窗口，再点「立即更新」（**不要点「稍后」**）→ 应出现**应用内下载进度**。  
2. 系统安装窗口点「安装」。  
3. 重新打开书然：全屏「需要更新书然」消失，能进首页。  
4. 「我的」里若站长可见版本，安装包应为 1.5.4。

### 5. 确认可关新加坡之后

- 只保留香港；不必再登录新加坡。  
- 未升级的旧外壳会失效；用户需用浏览器打开  
  `http://43.161.238.165:8000/download`  
  下载后覆盖安装。  
- 关机器前再确认：香港 `/download/info` 仍 available，且用户能登录。

## 到期后还要不要登录新加坡？

**善后完成并确认后：不需要。** 关阿里云新加坡实例即可。关之前不要删香港数据、不要 `compose down -v`、不要 `DROP SCHEMA`。
