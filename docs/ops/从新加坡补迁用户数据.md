# 从新加坡补迁用户数据到香港

迁站时只把用户账号迁到了香港，行动、待办、笔记、录音这些内容表当时没有一起收尾。这是当时的失误，现在补迁，不是用户该自己发现的。

时间日志已经合并过，**不要再导出、不要再插入、不要再 COUNT `time_log_nodes`**。

新加坡库可能是旧结构。`future_actions` 是香港后来才有的表；新加坡没有这张表就跳过，**不是数据丢了**。计数和导出都先看库里实际有哪些表，没有的表跳过，不要硬查。

## 铁令（违反就停）

1. 屏幕出现 `ERROR`，立刻停，不要做下一步。
2. 不要执行 `DROP SCHEMA`。
3. 不要执行 `docker compose down -v`，不要加 `-v`。
4. 不要改香港已经存在的用户（密码、套餐、名字都不改）。
5. 不要导入 `subscriptions`（订阅）、`invite_codes`（邀请码）。
6. 不要再碰 `time_log_nodes`。

按邮箱对齐。香港没有的邮箱会新建账号（带新加坡的登录密码）。香港已有的邮箱只补内容，不改账号。对不上的外键写成空；行动日志、录音播放、AI 对话若缺对应行动则跳过该行。

## 第 2 步：新加坡先列出表，再数存在的表

整段粘贴。没有的表会打印 `SKIP_NOT_EXISTS`，这是正常的。不要查 `time_log_nodes`。

```bash
set -e
cd /opt/shuran-app/deploy/aliyun
mkdir -p /tmp/sg-backfill

pg () {
  docker compose exec -T db psql -U reading_app -d reading_feedback -v ON_ERROR_STOP=1 "$@"
}

echo "=== public 全部表 ==="
pg -c "SELECT tablename FROM pg_tables WHERE schemaname = 'public' ORDER BY 1;"

echo "=== 用户内容相关、实际存在的表 ==="
pg -c "
SELECT tablename
FROM pg_tables
WHERE schemaname = 'public'
  AND tablename IN (
    'users','actions','practice_logs','daily_todos','daily_tasks','daily_schedules',
    'future_actions','reading_entries','self_talks','self_talk_playback_logs',
    'ai_advice_sessions','ai_advice_messages','self_talk_reminder_settings',
    'self_talk_reminder_logs','ai_call_logs'
  )
ORDER BY 1;
"

: > /tmp/sg-backfill/sg_counts.txt
echo "=== 存在的表行数（没有的跳过）==="
for t in users actions practice_logs daily_todos daily_tasks daily_schedules future_actions reading_entries self_talks self_talk_playback_logs ai_advice_sessions ai_advice_messages self_talk_reminder_settings self_talk_reminder_logs ai_call_logs
do
  exists=$(pg -tAc "SELECT to_regclass('public.${t}') IS NOT NULL" | tr -d '[:space:]')
  if [ "$exists" = "t" ]; then
    pg -c "SELECT '${t}' AS t, count(*) FROM ${t}" | tee -a /tmp/sg-backfill/sg_counts.txt
  else
    echo "${t} SKIP_NOT_EXISTS" | tee -a /tmp/sg-backfill/sg_counts.txt
  fi
done

echo SG_COUNTS_OK
```

成功：最后一行是 `SG_COUNTS_OK`。`future_actions SKIP_NOT_EXISTS` 是正常的（新加坡旧库没有这张表，不是数据丢了）。把整段输出留着，后面香港要对照。  
失败：有 `ERROR` 就停，不要做第 3 步。

## 第 3 步：新加坡导出其余表（不要导时间日志）

第 2 步最后出现 `SG_COUNTS_OK` 之后，再整段粘贴。用 CSV，避免正文换行把导入弄坏。没有的表会打印 `SKIP`，继续下一张。

dump_csv () {
  local name="$1"
  local sql="$2"
  local exists
  exists=$(docker compose exec -T db psql -U reading_app -d reading_feedback -tAc \
    "SELECT to_regclass('public.${name}') IS NOT NULL" | tr -d '[:space:]')
  if [ "$exists" != "t" ]; then
    echo "SKIP ${name} (新加坡没有这张表，不是数据丢失)"

load_csv () {
  local table="$1"
  local file="$2"
  if [ ! -f "/tmp/sg-backfill/${file}" ]; then
    echo "SKIP ${table} (没有 ${file}，新加坡没有这张表，不是数据丢失)"
