# 香港服务器购买流程

配套待办见 `docs/ops/未来规划与待办.md`。买到后把公网 IP 发给助手再迁站。

当前生产机是腾讯云香港 `43.161.238.165`。新加坡旧机 `47.236.122.207` 迁完后可关，但先留几天。

## 选哪一档（腾讯云锐驰）

| 优先级 | 套餐 | 标价（约） | 什么时候选 |
|---|---|---|---|
| 首选 | 锐驰 2 核 4G / 60GB 盘 / 200Mbps 无限流量 | 约 95 元/月 | 预算够，盘和内存更从容 |
| 能接受 | 锐驰 2 核 2G / 40GB 盘 / 200Mbps 无限流量 | 约 55 元/月 | 最低可用，盘偏紧 |

时长：先买 **1 个月**。香港小规格几乎没有年付折扣，迁通了再续。

价格以购买页为准。

## 一、腾讯云（先走这条）

### 准备

1. 打开 https://cloud.tencent.com 登录。没有账号就注册，并用身份证做**实名认证**。
2. 右上角费用中心充值，至少充 **100 元**（2 核 4G 一个月大约 95 元）。
3. 购买直达页：https://buy.cloud.tencent.com/lighthouse  
   控制台：https://console.cloud.tencent.com/lighthouse

### 购买页怎么选

按顺序核对，选错地域或套餐类型就退回去重开，不要将就。

1. **地域**：中国香港（有香港一区/二区/三区就随便一个能下单的）。  
   不要选广州、上海、新加坡。
2. **实例套餐**：点 **锐驰型**。  
   看到「入门型」不要点。
3. **规格**（二选一）：
   - 2 核 4G、60GB SSD、200Mbps、无限流量（优先）
   - 2 核 2G、40GB SSD、200Mbps、无限流量（预算紧）
4. **镜像**：系统镜像 → Ubuntu 22.04 或 Ubuntu 24.04。不要选 WordPress/宝塔应用镜像。
5. **实例名称**：`shuran-hk`
6. **登录方式**：自定义密码。密码自己记在密码管理器，不要发给任何人（包括助手）。
7. **购买时长**：1 个月。数量 1 台。
8. **防火墙**：创建后立刻改（见下面）。有的购买页可以勾选放行 80/443，22 一般默认开。

点「立即购买」→ 核对地域必须是中国香港、套餐必须是锐驰 → 提交订单 → 支付。

成功：1–3 分钟后，控制台列表出现实例，状态为「运行中」，并能看到**公网 IP**。

如果购买页提示该地域无库存、锐驰灰色、或只能选入门型：不要下单，改走下面「其他选项」。

### 买完立刻做

1. 控制台打开这台机器 → **防火墙**：
   - 放行 TCP 22（SSH）
   - 放行 TCP 80、443（以后 HTTPS 域名）
   - 放行 TCP 8000（现在应用端口，和现网一致）
   - 不要对全网开放 5432（数据库）
2. 点「登录」或本机 PowerShell：

```powershell
# 把 x.x.x.x 换成控制台里的公网 IP
ssh root@x.x.x.x
```

成功：问密码后进去，提示符变成 `root@...#`。

3. 把公网 IP 发给助手，开始从 `47.236.122.207` 迁数据。在此之前不要关掉新加坡那台。

## 二、腾讯云买不到时

按这个顺序试，不要同时买两台。

### 2. UCloud 香港轻量

1. 打开 https://www.ucloud.cn 注册并实名。
2. 控制台搜索「轻量应用云主机」或打开香港活动页：https://www.ucloud.cn/site/active/hk-global.html
3. 地域选 **香港**，不要选国内。
4. 套餐尽量 2 核 2G 或 2 核 4G，系统盘 ≥ 40GB，要公网 IP。
5. 镜像 Ubuntu 22.04，设 root 密码。
6. 先看清活动规则：有的新客年付很便宜，但可能不能退、不好扩容。不确定就买月付。
7. 防火墙同样放行 22、80、443、8000。
8. 能 SSH 登录后把 IP 发给助手。

### 3. 华为云香港 ECS

1. 打开 https://www.huaweicloud.com 注册并实名。
2. 控制台 → 弹性云服务器 ECS → 购买弹性云服务器。  
   直达可搜：https://console.huaweicloud.com/ecm
3. **区域必须选「中国-香港」**。买完不能换区域。不要选新加坡或国内。
4. 计费：包年/包月，先 1 个月。
5. 规格：2 核 4G 左右；系统盘 ≥ 60GB；镜像 Ubuntu 22.04。
6. 网络：分配弹性公网 IP；带宽先 5Mbps 即可。
7. 安全组放行 22、80、443、8000；不要放行 5432。
8. 设 root 密码，购买，SSH 登录成功后把 IP 发给助手。

华为云步骤比轻量产品多（VPC、安全组、弹性 IP），只有腾讯云和 UCloud 都没货时再走。

### 4. 阿里云香港再试一次

轻量爆款常卖空，可以换入口：

1. 轻量：https://swas.console.aliyun.com 地域换「中国香港」，换可用区再试。
2. ECS：https://ecs.console.aliyun.com 中国香港，按量付费先开起来，再转包月。

能买到阿里云香港，账号习惯最接近现在，但仍要锐驰/正式 ECS，不要捡特别小的国际型 0.5G 内存。

### 5. 都没货：先续新加坡

现网已经在新加坡跑着。续费或新开一台同规格新加坡机器，服务不中断，香港有货再迁。

AWS Lightsail 香港（https://lightsail.aws.amazon.com ）可以以后再考虑：内地线路一般，需要国际卡，不是现在的第一选择。

## 买错了怎么办

- 地域选成广州/上海：那是大陆机，要备案。退掉重买香港。
- 买了入门型香港：跨境会抖，退掉或不要当主站。
- 付完但 SSH 不上：先在控制台看防火墙是否放行 22，再「重置密码」。
- 不要同一天买两家各一台「先试试」——容易忘了哪台是主站，也多花钱。
