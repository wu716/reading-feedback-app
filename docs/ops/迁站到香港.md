# 迁到腾讯云香港

香港机：`43.161.238.165`（已购买，尚未切流量）  
旧机：`47.236.122.207`（阿里云新加坡，迁通前不要关）

切流量之后新加坡仍可能写下新数据。补迁用户内容见 `docs/ops/从新加坡补迁用户数据.md`。禁止 `DROP SCHEMA`，禁止 `docker compose down -v`。

本机没有 SSH 密钥，助手不能代登。用腾讯云网页终端操作新机；旧机用本机 PowerShell。密码不要发给助手。

## 第 0 步：新机防火墙（控制台点几下）

1. 打开 https://console.cloud.tencent.com/lighthouse
2. 点这台香港机器 → **防火墙**
3. 添加规则：协议 TCP，端口 **8000**，策略允许，来源 `0.0.0.0/0`
4. 确认已有 **22**。80、443 有更好，没有也可后补

成功：防火墙列表里能看到 8000。

## 第 1 步：新机装 Docker 并拉代码（腾讯云网页登录）

控制台点这台机器右上角 **登录**（网页终端，一般免密）。

粘贴整段，回车：

```bash
set -e
export DEBIAN_FRONTEND=noninteractive
apt-get update
apt-get install -y ca-certificates curl git
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker
docker --version
docker compose version
mkdir -p /opt
if [ ! -d /opt/shuran-app/.git ]; then
  git clone https://github.com/wu716/reading-feedback-app.git /opt/shuran-app
else
  cd /opt/shuran-app && git pull origin main
fi
mkdir -p /opt/shuran-app/releases /opt/shuran-app/deploy/aliyun
echo "NEW_SERVER_READY"
hostname -I
```

成功：最后打出 `NEW_SERVER_READY`，且 `docker compose version` 有版本号。  
失败常见原因：没联网、git clone 被墙。香港一般可以直接 clone GitHub。

先不要 `docker compose up`：还没有 `.env` 和数据库备份。

## 第 2 步：旧机备份（本机 PowerShell）

```powershell
# 当前目录：任意
# 目的：登上新加坡旧机
ssh root@47.236.122.207
```

成功：出现 `root@...#`。然后在**服务器**里执行：

```bash
set -e
cd /opt/shuran-app
mkdir -p /root/shuran-migrate
# 环境变量（哪有拷哪）
if [ -f deploy/aliyun/.env ]; then cp -a deploy/aliyun/.env /root/shuran-migrate/env; fi
if [ -f .env ]; then cp -a .env /root/shuran-migrate/env-root; fi
# 数据库
docker compose -f deploy/aliyun/docker-compose.yml exec -T db pg_dump -U reading_app reading_feedback > /root/shuran-migrate/shuran.sql
# 上传文件（卷名以 compose 项目目录为准）
UPLOAD_VOL=$(docker volume ls -q | grep -E 'uploads' | head -n 1)
if [ -n "$UPLOAD_VOL" ]; then
  docker run --rm -v "${UPLOAD_VOL}:/data" -v /root/shuran-migrate:/backup alpine tar czf /backup/uploads.tgz -C /data .
fi
# APK
cp -a /opt/shuran-app/releases /root/shuran-migrate/releases 2>/dev/null || true
ls -lh /root/shuran-migrate
echo "OLD_BACKUP_READY"
```

成功：看到 `OLD_BACKUP_READY`，且 `shuran.sql` 不是 0 字节。  
`pg_dump` 若报用户/库名不对，把容器里的实际用户发我（不要发密码）：

```bash
docker compose -f /opt/shuran-app/deploy/aliyun/docker-compose.yml exec db env | grep POSTGRES
```

备份仍留在旧机 `/root/shuran-migrate`。输入 `exit` 回到本机。


## 第 4 步：香港机恢复并启动（网页终端再贴一次）

```bash
set -e
cd /opt/shuran-app
# 放 .env
if [ -f /root/shuran-migrate/env ]; then
  cp -a /root/shuran-migrate/env /opt/shuran-app/deploy/aliyun/.env
elif [ -f /root/shuran-migrate/env-root ]; then
  cp -a /root/shuran-migrate/env-root /opt/shuran-app/deploy/aliyun/.env
else
  echo "缺少 .env，停下来" >&2
  exit 1
fi
# APK
mkdir -p /opt/shuran-app/releases
cp -a /root/shuran-migrate/releases/. /opt/shuran-app/releases/ 2>/dev/null || true

cd /opt/shuran-app/deploy/aliyun
docker compose up -d --build
# 等数据库起来
sleep 15
docker compose exec -T db pg_isready -U reading_app

# 导入数据（先清空库再导入，避免空库默认表冲突）
docker compose exec -T db psql -U reading_app -d reading_feedback -c "DROP SCHEMA public CASCADE; CREATE SCHEMA public;"
docker compose exec -T db psql -U reading_app -d reading_feedback < /root/shuran-migrate/shuran.sql

# 恢复上传文件
UPLOAD_VOL=$(docker volume ls -q | grep -E 'uploads' | head -n 1)
if [ -f /root/shuran-migrate/uploads.tgz ] && [ -n "$UPLOAD_VOL" ]; then
  docker run --rm -v "${UPLOAD_VOL}:/data" -v /root/shuran-migrate:/backup alpine tar xzf /backup/uploads.tgz -C /data
fi

docker compose ps
curl -fsS http://127.0.0.1:8000/health
echo "HK_UP"
```

成功：打出 `HK_UP`。本机浏览器打开：

http://43.161.238.165:8000

能打开登录页，用旧账号能登录，就说明数据过来了。
