# 启用知间与书然账号联动

适用：香港服务器 `43.161.238.165` 上，书然 2.0.26 / versionCode 68 使用 `/opt/shuran-app/deploy/aliyun` 的 Docker Compose，知间 0.1.16 使用 `/opt/learning-reader` 和 `learning-reader` systemd 服务。2026-10-24 已直接验证知间 `https://43.161.238.165/api` 返回 0.1.16。服务凭证的实际配置状态不能通过公开健康接口判断。

“知间联动尚未配置”表示书然运行容器尚未满足来源地址、服务身份、至少 32 字符服务密钥和安全的既有 SECRET_KEY 等启用条件。程序部署不会自动生成两端凭证；本人账号关联也尚未开始。两端账号通过双向确认建立对应，不按邮箱或数值用户 ID 自动合并。

## 本次方案

使用已有 HTTPS 来源 `https://43.161.238.165`，保持 Nginx、知间的本机 8010 监听和两个独立数据库。书然在 Docker 中，容器的 `127.0.0.1` 不是服务器宿主机，不能把来源地址直接填成 `http://127.0.0.1:8010`。

脚本先从书然容器测试 HTTPS 连接，核对既有 SECRET_KEY 安全性，然后对现有两个 `.env` 做私密备份。已存在的完整凭证会复用；两端均为空时在服务器内存中生成同一强随机值，分别写入相应服务配置。凭证不打印，不加入 Git；两端冲突、部分填写或来源不同则停止，不能悄悄轮换已有授权。原 SECRET_KEY、数据库、书籍、附件和其他配置项不改动。

配置写入失败时恢复原文件；重启/连接检查失败时保留配置和备份，并显示失败阶段，由管理员依据该阶段处理。脚本会短暂重启知间、重新创建书然应用容器以读取新环境变量，不重建数据库容器。此操作由用户执行。

## 执行命令

Windows PowerShell（已在服务器终端则跳过）：

```powershell
ssh ubuntu@43.161.238.165
```

登录 Ubuntu 后（已经是 root 则跳过第一行）：

```bash
sudo -i
cd /opt/shuran-app && git pull origin main
/opt/learning-reader/.venv/bin/python /opt/shuran-app/deploy/aliyun/configure-reader-sync.py
```

使用知间既有虚拟环境，依赖已有 python-dotenv，不在宿主机临时安装工具。配置备份保存到 `/opt/shuran-release-backups/reader-sync-*` 的私密目录。脚本以权限 600 写入配置，知间配置归既有 reader 服务账号。来源地址已经有其他值、凭证不一致、默认/过短 SECRET_KEY、缺少预期配置文件或连接失败时，不继续自动启用；仅提供脚本的阶段提示，不向聊天发送实际 `.env` 内容。

最后应看到“联动通道已启用”。验证使用不存在的请求 ID，要求受机器认证保护的来源状态接口返回明确的 Unknown pairing request；不创建关联、不领取个人授权、不写入阅读数据。它验证的是机器通道，不能替代本人账号的双向确认。

可独立复查健康状态：

```bash
curl --retry 12 --retry-delay 3 --retry-all-errors --retry-max-time 90 --connect-timeout 5 --max-time 10 -fsS http://127.0.0.1:8000/health
curl --retry 12 --retry-delay 3 --retry-all-errors --retry-max-time 90 --connect-timeout 5 --max-time 10 -fsS https://43.161.238.165/api
```

若知间重启失败，读取 `journalctl -u learning-reader -n 100 --no-pager`；若书然应用重建/就绪失败，运行 `cd /opt/shuran-app/deploy/aliyun && docker compose ps -a && docker compose logs --tail=100 app`。保留备份，不删除持久卷或重置账号。

## 页面验收

1. 书然 → 长期目标 → 每日记录 → 知间阅读联动 → 刷新状态。应可生成 10 分钟关联码。
2. 在已登录的知间“关联书然”页输入码，核对两个账号，选择授权日期和书名方式，点击“确认账号与阅读授权”。
3. 返回书然，点击“已在知间确认，读取账号信息”，核对后点击“确认关联这两个账号”。
4. 在知间前台实际阅读两本书，返回并等待保存完成，在“阅读记录”核对今天各书时长。书然点击“立即同步”；先保存未保存的每日填写，再“重新读取”当天明细。
5. 按页面精度核对逐书时长。重复同步不应增长；新增阅读保存后，约 5 分钟的后台同步应能更新。旧累计没有具体日期，不会伪造到今天。
