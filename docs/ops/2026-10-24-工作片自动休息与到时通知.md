# 工作片自动休息与到时通知

版本：服务端 / Android 2.0.28，versionCode 70；Windows 1.6.5；网页缓存版本 20261024focus1。

## 行为与兼容

- 工作片自然到时保存截止区间，并以该截止时刻为起点创建休息。默认5分钟，使用现有休息时长设置。
- 迟到打开时补结算已经发生的工作和休息，不补记无人执行的工作。重复读取不重复创建休息。
- 暂停 / 提前结束工作不自动休息；提前结束休息只结束当前休息，下一项仍需主动开始。
- 服务端使用现有 WorkSession / ExecutionPlan，不新增数据库表、不迁移或删除历史业务数据。
- Windows 本机计时独立于网页可见状态，系统通知不主动打开主窗口；点击通知才打开执行页。普通关闭软件将停止本机计时，不承诺退出后的闹钟。
- Windows 系统横幅外观、位置、持续时间服从系统设置，不能与网页自定义示例逐像素一致。回落拨弦由本机播放一次，系统默认通知音静音，避免叠音；独立音频播放受设备音量控制，但不会继承系统横幅所有免打扰规则。
- Android 本地闹钟在工作到时后继续安排休息到时闹钟；主备闹钟及前台刷新防重复。独立通知渠道使用选定铃声，其他待办提醒渠道不受影响。须授予通知和准确闹钟权限，厂商后台限制须在实机验收。
- 网页前台使用右下角提醒，8秒收起，休息倒计时继续；已安装旧桌面壳须更新后才有新的原生能力。

## 用户执行部署

先在 Windows PowerShell 上传新安装包到服务器用户主目录，然后 SSH。代理不执行生产部署。

```powershell
Set-Location D:\projects\reading-feedback-app
scp "D:\UserData\ProjectArtifacts\reading-feedback-app\focus-reminder-implementation\shuran-2.0.28.apk" ubuntu@43.161.238.165:~/shuran-2.0.28.apk
scp "D:\UserData\ProjectArtifacts\reading-feedback-app\focus-reminder-implementation\windows\Shuran.exe" ubuntu@43.161.238.165:~/shuran-windows-1.6.5.exe
ssh ubuntu@43.161.238.165
```

在 Ubuntu 执行：

```bash
sudo -i
cd /opt/shuran-app
git pull origin main
install -m 644 /home/ubuntu/shuran-2.0.28.apk releases/shuran.apk
printf '70\n' > releases/shuran.apk.versioncode
install -m 644 /home/ubuntu/shuran-windows-1.6.5.exe releases/shuran-windows.exe
sha256sum releases/shuran.apk releases/shuran-windows.exe
cd deploy/aliyun
docker compose up -d --build
curl -fsS http://127.0.0.1:8000/health
curl -fsS http://127.0.0.1:8000/download/info
```

比对 APK/EXE 摘要与 `releases/latest.json` / `releases/windows-latest.json`。安装新 Android / Windows 客户端后，开始一片并切至其他应用，实际确认工作到时提醒、自动休息、休息到时、提前结束及无重复发声。确认 APK 已发布可下载后再清理本地构建包。
