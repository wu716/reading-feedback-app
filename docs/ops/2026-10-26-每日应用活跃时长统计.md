# 每日应用活跃时长统计

## 产品口径

- 仅统计已登录账户。应用页面处于前台，且最近两分钟内有鼠标、键盘、触摸或滚轮操作时累计；切后台、锁屏或闲置两分钟后暂停。
- 首次使用新版时先显示统计说明；确认后才开始发送计时心跳。「我的 → 数据与帮助」保留相同口径说明。
- 服务端以北京时间归档自然日；跨午夜的心跳间隔拆分到两天。同一账号多个页面或设备的重叠区间按并集累计。
- `daily_app_usage` 保存账号关联、日期和累计秒数。心跳时间仅作短期并发去重状态，失活后清除；每日总量保留最近90个北京时间自然日，清理不回写其他业务数据。
- 仅站长接口 `GET /owner/usage` 返回明细，由现有 `get_current_owner` 权限检查保护；计时接口 `POST /api/usage/pulse` 要求登录。访客不计入，历史数据不补算。
- 不采集页面内容、输入文字、设备来源、IP或浏览行为。网络中断、进程被系统强制挂起时可能漏计少量时间；这项指标是前台活跃时间估算，不代表用户全程注意力。
