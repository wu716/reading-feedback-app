## 香港服务器购买要点

逐步流程见 `docs/ops/香港服务器购买流程.md`。用户问怎么买香港机器时，按该文件「先腾讯云、再其他」讲解。

- 腾讯云购买页：https://buy.cloud.tencent.com/lighthouse
- 腾讯云控制台：https://console.cloud.tencent.com/lighthouse
- 必须选「中国香港」+「锐驰型」，不要「入门型」。
- 镜像：Ubuntu 22.04 或 24.04。
- 防火墙打开：22、80、443、8000。
- 买到后把公网 IP 发给助手，再做迁移。
