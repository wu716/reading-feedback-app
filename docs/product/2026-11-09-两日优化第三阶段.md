# 第三阶段：计划周期日期调整

原需求：**“计划周期，开始、结束时间无法修改”。**

项目 → 计划周期与复盘 → 调整周期日期，进入独立页面修改起止日期。页面从现有周期读取反馈节点，逐项提供“保留原日期／指定新日期”；保存前列出每项最终日期，范围外节点明确提醒。已提交或已跳过节点仅展示，不可改期。改期不会新增或删除反馈节点。

服务器在同一事务检查周期原日期、每个可改期节点的原日期、节点集合和日期冲突，记录调整前后快照。周期的历史投入与提交记录保持原有日期；周期统计按新范围重新计算。改动节点日期时取消尚未发送的旧邮件提醒并标记旧提醒已处理，后续提醒按新日期生成。已有提醒记录不删除。旧提醒键兼容，未改期的用户不会因升级重复收到提醒。
