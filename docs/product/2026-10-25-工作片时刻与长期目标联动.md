# 工作片、时刻与长期目标联动 · 2.0.35

版本：2.0.35；Android 源码 versionCode 77；静态资源 20261025worklink1。

## 已确认的行为

用户已审核独立合成页面并授权实施。工作片开始自动展示关联时刻，结束后更新完整实际区间；暂停和恢复形成分开的实际区间。休息、暂停、等待不计工作。长期目标自动接收已结算工作片，默认归入工作，也可以改分类。服务器到点封顶，跨北京时间午夜拆分到对应日期。

在长期目标可补记、修改标题、分类、时长、备注，排除／恢复计入和恢复自动同步。独立修改不反写任务实际投入，也不被源更新覆盖。更正原工作片则更新任务投入和时刻区间，长期目标已独立修改的值保留并提示来源变化。未保存草稿先保存，再更正来源或导入历史。

手动时刻可以确认实际开始结束时间，任务关联选填；也可以直接关联已有工作片。只记录时间点不推算时长；区间重叠拒绝写入。确认接口重试返回同一来源。删除文字时刻不删除工作片；关联后原时刻间隔不再次计入长期目标。手动明细可标记与工作片相同，仍保留内容但不重复累计时间或次数。

「记」保留时刻、idea、以后想做等宽三列。时刻入口内展示最近三条关联片段；回看时刻提供完整日明细与补充记录、更正区间。进行中的工作片标为计时中，结束后才进入长期目标正式统计。

## 存储与兼容

- 两张新增表 `work_link_settings`、`work_moment_links` 随既有幂等建表创建；不修改旧工作片、时刻或日记录列，不创建本地业务库。
- 首次新增工作片记录自动启用边界；边界以前的旧工作片不直接回填，在长期目标提供按日历史核对导入。由用户确认后再加入，旧手动记录继续保留，可核对去重。
- 长期目标的覆盖值和来源 ID 保存在现有每日明细 JSON 中，所有报告和目标进度共用去重口径。原始投入与统计调整分别保留。
- 账号归属、稳定来源身份、重复引用和区间重叠由服务端校验；沿用每日 revision 和原子保存，过期客户端不能覆盖已联动日期的明细。
- 两张新表纳入逻辑备份和本人数据导出；旧表不删除，服务器业务数据与上传卷保留。
